# Week 3: Advanced Data Analysis and Visualization in Logistics

## Project Overview
This project focuses on advanced data analysis and visualization in logistics using Python. It demonstrates how data analysis techniques can help identify shipment patterns, evaluate delivery performance, and support better supply chain decisions.

The project uses a hypothetical logistics dataset containing 600 shipment records.

## Objectives
- Perform Exploratory Data Analysis (EDA).
- Calculate descriptive statistics and measures of central tendency.
- Analyze shipment costs and delivery times.
- Identify correlations between logistics variables.
- Create visualizations to understand logistics performance.
- Generate insights and recommendations for improvement.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab

## Dataset Description
The dataset contains hypothetical shipment information, including:
- Shipment distance
- Delivery time
- Shipping cost
- Transportation mode
- Region
- Shipment date
- Shipment volume

**Note:** The dataset is simulated for educational and analytical purposes. It does not represent actual company operations.

## Analysis and Visualizations
The project includes:
1. Delivery time distribution (Histogram)
2. Delivery time comparison by transportation mode (Boxplot)
3. Relationship between shipping cost and distance (Scatter Plot)
4. Regional delivery performance (Bar Chart)
5. Monthly shipment trends (Line Chart)
6. Correlation analysis (Heatmap)

## Key Findings
- The overall on-time delivery rate is approximately 76.7%.
- Average delivery time is approximately 5.95 days.
- Delivery performance varies across transportation modes.
- Shipment distance and shipping cost show a positive relationship.
- Regional and monthly patterns provide useful insights into logistics operations.

## Project Files

- `Week_3_Hypothetical_Logistics_Dataset.csv` – Dataset used for the analysis.

## Conclusion
This project demonstrates how Python-based data analysis and visualization can help improve logistics efficiency, monitor shipment performance, identify operational patterns, and support informed supply chain decisions.
